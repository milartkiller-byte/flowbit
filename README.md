# Flowbit

Сайт продукту Flowbit — бездротового датчика вібрації й температури для двигунів, насосів і вентиляторів.

- Сайт: https://milartkiller-byte.github.io/flowbit/
- English: https://milartkiller-byte.github.io/flowbit/#en
- 3D-модель насосного агрегату К80-50-200: https://milartkiller-byte.github.io/flowbit/k80-50-200.html

Файли:

- `index.html` — лендінг, увесь в одному файлі.
- `k80-50-200.html` — 3D-сторінка: модель по деталях, точки датчиків, несправності й покрокові процедури ремонту (Three.js).
- `models/k80-50-200.glb` — модель із Blender (стиснення Draco).
- `img/k80-unit.webp` — заставка, поки вантажиться 3D.
